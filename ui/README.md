# UI Design Notes

本目录保存首页重设计参考图。

## 文件

- `home-light.png` - 首页浅色模式设计图。
- `home-dark.png` - 首页深色模式设计图。

## 设计方向

首页采用桌面原生 App 风格的三栏结构：

- 左侧：应用导航与来源筛选。
- 中间：Skill Library 列表，只保留高频扫描信息。
- 右侧：紧凑 Inspector，展示完整详情与操作。

中间列表只显示名称、短描述、来源图标、Agent 只读状态和待处理状态。仓库、路径、安装时间、锁定版本等低频信息放入右侧详情，避免重复。

## 关键交互

- 顶部按钮使用 `检查更新`，语义是刷新列表并重新计算更新状态。
- 列表中的 Agent badge 只读，不承担安装或移除操作。
- Agent 操作只在右侧 `Agent 安装` 区域完成。
- 右侧操作按钮分两排：
  - `打开文件夹` / `检查更新`
  - `退出调试` / `删除`
- `删除` 使用弱红色文字或描边，不使用大面积红底。

## 字段说明

`锁定版本` 对应当前 lock entry 的 `folderSha`，用于判断 Skill 是否有更新。它是内容快照 SHA，不是语义化版本号。

本地来源也会计算目录内容哈希，因此可以显示同样的锁定版本字段。
